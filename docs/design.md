# 布局与刷新约定

所有坐标以竖屏左上角为原点，单位像素。1 px = 0.2 mm。

| 区域 | 坐标 / 尺寸 |
| --- | --- |
| 画布 | 480×800 / 96×160 mm |
| 天气栏 | y=0..127，城市、天气图标、天气描述、室外温度、风力与气象时间 |
| 照片 | (24,140,432,576)，86.4×115.2 mm |
| 室内读数 | y=735..762，温度与湿度来自 SHTC3 |
| 底栏 | y=773..799，采样时间与每小时更新提示 |

底栏标注“采样于 HH:MM”和“每小时更新”。天气栏的气象时间来自服务端，与室内采样时间独立。顶部不用大时钟。

## 兼容路径

```
原图文件 (JPG / PNG / BMP)
 → 文件与尺寸上限检查
 → 解码（PSRAM），透明通道合成白色
 → JPEG EXIF 1–8 虚拟方向变换（不额外复制整图）
 → cover 居中裁切 / contain 留白
 → 仅在照片框进行双线性采样、六色 Floyd–Steinberg 抖动
 → 在独立区域绘制实时状态与黑白文字
 → 480×800 逻辑画布旋转至 800×480 面板
 → 192000 字节 4bpp SPI 数据
```

面板色码是 `0 黑 / 1 白 / 2 黄 / 3 红 / 5 蓝 / 6 绿`，不是调色板数组的连续编号。旋转发生在整个界面合成之后，照片尺寸不会影响 SPI 帧长度。

相对于 800×480 图，默认 cover 使用中央 360×480 部分再缩放到 432×576。contain 使用 432×259 内容，放在照片框中央，四周保持白色。已规范化为 432×576 的照片不再裁切。

## 板级连接

与固定版本官方 `user_app.cpp` / `sdcard_bsp.h` 一致：

| 外设 | 连接 |
| --- | --- |
| E6 SPI | MOSI 11、SCLK 10、DC 8、CS 9、RST 12、BUSY 13；SPI3，40 MHz |
| I2C | SDA 47、SCL 48；100 kHz |
| SHTC3 | 0x70，双通道 CRC 校验 |
| PCF85063 | 0x51，UTC、BCD/日期与振荡器停止检查 |
| PMIC | 0x34，官方 XPowers AXP2101 接口；读取失败不伪造电量 |
| SDMMC 4-bit | CLK 39、CMD 41、D0 40、D1 1、D2 2、D3 38 |
| 手动唤醒 | BOOT 0、KEY 4，低电平唤醒 |

参考 RTC 数据手册：https://www.nxp.com/docs/en/data-sheet/PCF85063A.pdf
